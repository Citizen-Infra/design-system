# Changelog

## 0.2.0-draft.1

Opt-in Open Index treatment: bright yellow/blue core fields, coral/mint supporting fields, paired inverse/on-field roles, and large type throughout. Caption/UI floors rise to 20px-equivalent, body to 22px, display to 48–88px; control sizes grow accordingly. Public Sans binaries/licences and semantic status/data colours remain separate and unchanged. Original typographic brand assets and their provenance are refreshed to match the new treatment. Contract coverage expands to 120 contrast pairs plus type-floor tests. See migration notes before adopting; publishing this Git revision does not update any consumer or publish to npm.

## 0.1.0-draft.1

Initial extraction of Open Manual from the CIBC website pilot: namespaced semantic token contract, local licensed Public Sans, original typographic brand assets and source, public application guidance, and contract tests. GitHub-source publication only; no registry release or consumer migrations.
